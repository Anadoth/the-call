# Contributing

This repository is where we refine the description of The Call together. A few norms, kept light, so the way we collaborate on the document stays faithful to the practice it describes.

## How we work

- **Propose changes as pull requests, not direct pushes to `main`.** The point of version-controlling this is that changes are visible, discussed, and reversible. A PR is the written, reviewable form of "here's what I think should change and why" — which is the same posture the practice itself runs on.
- **Say why in the PR, and log substantive changes in `CHANGELOG.md`.** The git history records *what* changed; the changelog records *why*. We care most about the why.
- **Disagree in the open, decide together.** Unvarnished, received as a gift, none of it touching whether we stay. The same rule as the practice.

## What this repo is for

Refining the **description** of The Call — the map of something we are each living. It is not a substitute for the practice. If the document ever starts competing with the actual pairs for our attention, the pairs win. (See the note at the top of the README.)

This repo is about the **practice** — the relationship, the commitments, the way it spreads. Anything that isn't the description of the practice belongs somewhere else.
